### My Blog Application 
- This is a Blog Application In which multiple users can create Blog posts and can can see Other's Also .

### It Is made by combining many technologies . These are : 
1. React [ by vite ]
2. RTK [ Redux Tool Kit , react-redux - for state management ]
3. React-router-dom [ for Routing ] 
4. Appwrite [ open source , for Backend-as-a-Service [ Aunthentication , Authorization and Database ] ]
5. tinymce [ open source , for visual text editor ]
6. html-react-parser [ open souce , to understand the html to browser ]
7. React hook form [ open source , to use the external library of form that have extra features of form ]

### This is how the all installations at once look like :-
-  npm install @reduxjs/toolkit  react-redux react-router-dom appwrite @tinymce/tinymce-react html-react-parser react-hook-form
-  Here , we can install every technology one by one as the project grows and as we need them . But , in this
-  We have very well known that which technologies will be used [ As this project is planned / stratergic ]
